# APSII — Atividades Java

Repositório com exemplos e exercícios de programação orientada a objetos e padrões de projeto.

## Índice de atividades

- **atividades/exemplo1** — exemplo inicial com a classe Banco (nome, CPF e saldo) e programas simples de console.
- **atividades/exercicio2** — exercício de funcionários, com dados e cálculos na classe Funcionario; FuncionarioCLT está iniciado, mas incompleto.
- **atividades/exercicio3** — estrutura inicial com as classes Livro, CD e Principal, ainda sem implementação.
- **atividades/factory** — exemplo de pizzarias e fábricas de ingredientes por região, com pedidos de pizzas de estilos diferentes.
- **atividades/meu-projeto** — exemplo de herança e polimorfismo: Carro e Bicicleta especializam Veiculo e são usados por Pista.
- **atividades/padroes-de-projetos** — simulador de patos com comportamentos de voo e grasnido intercambiáveis, conforme a atividade de padrões de projeto.

## Importar no Eclipse

Para projetos com configuração Eclipse, use **File > Import > Existing Projects into Workspace** e escolha E:\apsii\atividades como diretório raiz. Selecione os projetos desejados e conclua a importação.

Os projetos com pom.xml são **exemplo1**, **exercicio2** e **exercicio3**. Para eles, também é possível usar **File > Import > Maven > Existing Maven Projects** e selecionar a pasta do projeto correspondente. O Exercicio3 inclui configuração Eclipse além do pom.xml.

Como os caminhos mudaram, projetos que já estavam no workspace podem precisar ser importados novamente.
